# 阅读桌与地图展示优化设计

## 目标

为 LitMap 增加一个独立的书桌阅读展示区，让当前图书以书本卡片的形式呈现在桌面上，并为每本书提供独立的阅读灯开关。同时提升地图初始视野与选书后的封面可读性，保持现有地图、侧栏、详情抽屉和筛选流程不变。

## 交互设计

- 阅读桌位于地图底部中央，默认收起为“阅读桌 · N 本”胶囊按钮。
- 展开后显示桌面、桌沿和最多 8 本书籍卡片。
- 有区域聚焦时展示当前区域书籍；没有区域聚焦时展示按排名排序的前 6 本。
- 点击书本封面调用现有 `SELECT_BOOK`，打开右侧详情抽屉。
- 每本书配置独立灯控按钮。灯控点击只改变该书的照明状态，不触发封面选中。
- 灯亮时显示暖黄色光晕、封面提亮和轻微呼吸效果；灯灭时恢复冷色低亮度。
- 灯控使用按钮语义和 `aria-pressed`，支持鼠标、键盘和焦点状态。
- 灯光状态保留在当前页面会话，不增加数据文件或持久化存储。

## 地图策略

- 地图初始缩放从 3 调整为 4.2，最低缩放提高为 3.2，保证首次打开时书籍封面标记具备可辨识尺寸。
- 单本书选中时飞行缩放从 8 调整为 9。
- 搜索和区域边界自适应后增加最小缩放保护，避免 fit bounds 结果过度缩小；不改变现有聚类层级和筛选逻辑。
- 初始中心仍保持当前文学数据密集的欧洲—亚洲视野。

## 组件与数据流

- 新增 `src/components/ReadingDesk/ReadingDesk.tsx` 和 `ReadingDesk.module.css`。
- `App.tsx` 负责将区域书籍、全量书籍和当前选中书籍传给阅读桌。
- 阅读桌内部维护 `Set<string>` 形式的亮灯书籍 ID，按书籍 ID 独立切换。
- 选择书籍仍通过现有 UI Context dispatch 完成，不新增 reducer action。
- `MapView.tsx` 仅调整视野参数和 fit bounds 的最小缩放保护。
- 动画使用局部 CSS keyframes，并遵守现有全局 `prefers-reduced-motion` 规则。

## 视觉与响应式

- 使用现有低饱和蓝绿色主题，灯光使用暖琥珀色作为对比色。
- 阅读桌不遮挡左右面板和底部时间轴的主要操作区域。
- 桌面宽度随视口变化：宽屏展示横向书列，小屏允许横向滚动并压缩卡片尺寸。
- 阅读桌展开/收起、书本入场、灯光切换和 hover 使用短时缓动动画。

## 验证标准

- `npm run build` 通过。
- `npm run lint` 通过。
- 阅读桌可展开和收起；每本灯控互不影响。
- 点击封面仍可打开现有详情抽屉，灯控不会误触发选书。
- 首次打开地图时封面标记比原状态更易辨识；选中图书后封面尺寸明显提升。
- 在 `prefers-reduced-motion` 下核心功能可用且不持续播放动画。
